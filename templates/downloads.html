Addresses

Each term has a web address made of a base address and its identifier, for example <>terms/CRK_102. The address opens the term's page, which also carries the term's data in JSON-LD for programs. The base address is provisional: the planned permanent form is <>CRK_102. The identifiers themselves will not change.

Earlier versions

Every release, with its files and its list of changes, is on GitHub releases. The changes are also on the release notes page.
