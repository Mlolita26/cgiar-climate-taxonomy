Downloads

The vocabulary in SKOS (Turtle and JSON-LD) and as a CSV, free to reuse.

The whole vocabulary in three formats. The files below are always the latest release; each release on GitHub keeps its own copy of them.

FileFormatWhat it holdsSize
climate-taxonomy.ttlSKOS, TurtleThe whole vocabulary: concepts, labels, synonyms, definitions and sources, hierarchy, facets, relations, retired identifiers.1074 KB
climate-taxonomy.jsonldSKOS, JSON-LDThe same content as the Turtle file, for programs that read JSON.1088 KB
climate-taxonomy.csvCSVOne row per concept and per retired identifier, for spreadsheets. Columns below.504 KB
meliaf-relations.ttlOWL, TurtleDefinitions of the properties the vocabulary adds to SKOS: the typed relations and the rule attributes.4 KB

Addresses

Each term has a web address made of a base address and its identifier, for example https://mlolita26.github.io/cgiar-climate-taxonomy/terms/CRK_102. The address opens the term's page, which also carries the term's data in JSON-LD for programs. The base address is provisional: the planned permanent form is https://w3id.org/cgiar/climate-taxonomy/CRK_102. The identifiers themselves will not change.

Earlier versions

Every release, with its files and its list of changes, is on GitHub releases. The changes are also on the release notes page.

Use it in code

LanguageExample
Rreadr::read_csv("https://mlolita26.github.io/cgiar-climate-taxonomy/dist/climate-taxonomy.csv")
Pythonpandas.read_csv("https://mlolita26.github.io/cgiar-climate-taxonomy/dist/climate-taxonomy.csv")
Command linecurl -O https://mlolita26.github.io/cgiar-climate-taxonomy/dist/climate-taxonomy.ttl

Columns of the CSV

ColumnMeaning
idIdentifier, for example CRK_102. Never reused.
iriWeb address of the term.
termPreferred label.
synonymsOther words for the same concept, separated by semicolons.
facetOne of the eleven facets.
levelDepth in the hierarchy (1 = top concept).
parent_idBroader concept. For a retired identifier: its successor, if any.
definitionDefinition. For a retired identifier: when and why it was retired.
definition_sourceAuthority the definition comes from.
pathway_stagePosition in the results chain.
climate_areaAdaptation, Mitigation, or Adaptation + Mitigation.
tagging_roleStand-alone (counts on its own) or Context-dependent.
context_ruleFor a context-dependent term: when it counts.
is_hazardTRUE for climate hazards.
provenanceWhere the concept came from.
review_statusHow the term is being reviewed (see About).
statuscurrent or deprecated.
versionVersion of the vocabulary.
